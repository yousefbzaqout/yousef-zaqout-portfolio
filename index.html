        Engineering Rigor & Performance

        N+1 eliminated. Latency collapsed.

        Direct side by side proof of query discipline, featuring eager loading, clean indexes, and measurable resource savings.

        102 → 2 queries · 380ms → 12ms View the code </>
        Unoptimized Query
        102 DB Queries 380ms 18MB RAM 
        // N+1: loads relations inside a loop
$orders = Order::all();
foreach ($orders as $order) {
  echo $order->user->email; // +1 query each
  echo $order->items->count();
}
        Optimized Query
        2 DB Queries 12ms 2MB RAM 
        // withCount: count without hydrating item models
$orders = Order::query()
  ->with(['user:id,email'])
  ->withCount('items')
  ->select(['id', 'user_id', 'total'])
  ->get();
foreach ($orders as $order) {
  echo $order->user->email;
  echo $order->items_count;
}
